# TankWorks 储罐设计器

参数化立式圆筒常压钢制储罐的工程设计、展开与预制放样网页应用。所有 3D、二维工程图、容量、材料统计、BOM 与导出均由同一个 `TankModel` 派生。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

生产构建与验证：

```bash
npm run build
npm run test
npm run lint
```

## 第一版闭环

- 默认项目 TK-101（Ø20 m × 16 m）
- 分圈、分板的罐壁 3D 模型与纵缝错缝
- 24 个周向分瓣、每瓣 3 个径向分段，共 72 块可单独选择的梯形顶板
- 径向瓣缝、环向分段缝、单面搭接/对接形式与搭接宽度显示及校验
- 中心柱、径向椽梁与环向梁组成的支承锥顶初步布置
- 单块梯形板下料图，并保留精确锥面面积用于差异核对
- 理论轮廓与加工余量轮廓
- 螺旋楼梯踏步、梯梁、扶手、平台、接管与人孔
- 实时液位、容量、质量、充装率与底部静液压
- 立面图、平面图、顶盖结构图、楼梯详图、罐壁展开、容量曲线与 BOM
- 当前页面 PNG/PDF、单块梯形顶板 DXF、罐壁展开 DXF、容量表 CSV、项目 JSON
- 制造演示：逐步查看顶板原板排样、精确展开与梯形近似、切割、预拼和骨架安装；查看楼梯踏步、梯梁、钢管分开备料及分段安装
- 参数校验与“未经规范校核”工程状态

## 工程边界

本版本用于几何方案、展开、预制排版、容量与材料初步统计。顶盖梁柱和楼梯详图属于初步几何布置，尚未实现 API 650、EN 14015、GB 50341 等完整规范结构验算，也不替代有资质工程师的制造图复核。球冠/拱顶、异形板智能套料、底板完整排版、XLSX 导出和规范校核保留为后续模块。
